# NextStep UX 가이드

> 기능은 많아지고 화면은 작다. 이 문서는 "생각하지 않고 쓰는" 앱을 지키는 규칙이다. 새 화면·기능은 여기 규칙에 맞지 않으면 구조를 바꾸지 말고 기능을 기존 자리에 넣는다.
> 목업: https://claude.ai/artifact/4PusAYfkqYUC2DR2qRT7Ey

## 1. 원칙 (우선순위 순)

1. **화면마다 질문 하나.** 오늘 = "지금 뭐 하면 되지?", 여정 = "다음은 뭐지?", 기록 = "어떻게 하고 있지?", 가족 = "누구와?". 한 화면이 두 질문에 답하면 쪼갠다.
2. **탭은 3개 + 기록 버튼 + 가족.** 역할이 달라도 뼈대는 같다. 탭을 늘리는 대신 새 기능은 (a) 오늘의 카드 한 장, (b) 여정 위의 항목 종류, (c) 기록의 세그먼트 중 하나로만 들어간다.
3. **쓰기는 전부 기록 버튼(+)으로.** 화면마다 편집 버튼을 두지 않는다. 시트는 항목 5개 이하, 각 항목은 필수 입력 3개 이하(예: 활동 기록 = 종류·제목·날짜).
4. **숫자보다 상태 문장.** 첫 화면은 "잘 가고 있어요 / 챙길 것 하나"처럼 한 문장으로 답한다. 숫자·그래프는 한 번 탭한 뒤에.
5. **지금 기준 3개.** 모든 목록은 지금 필요한 3개까지만 보여 주고 "전체 보기"로 확장한다. 스크롤로 기능을 발견하게 하지 않는다.
6. **시간이 곧 내비게이션.** 여정은 학기(구간) 단위로 접히고, 현재 구간이 열린 채 화면 위쪽에 온다. 위는 과거, 아래는 미래.
7. **상세는 바텀시트.** 맥락을 유지한다. 전체 화면 전환은 편집기(긴 입력)와 타이머뿐이다.
8. **카드 해부학은 하나.** 라벨(12px 회색) / 제목(16px 굵게, 한 줄) / 보조(13px 회색, 한 줄) / 오른쪽 행동 1개(버튼 또는 화살표). 카드당 행동은 하나.
9. **기록 마찰 0.** 학생 첫 화면 최상단은 타이머 큰 버튼. 완료는 체크 한 번. 활동 기록은 세 필드. 학생 화면엔 광고도 유료 벽도 없다.
10. **비교 없음, 상한 있음.** 또래·전국 비교 지표를 그리지 않는다. 학습량이 성장 단계 상한을 넘으면 "줄이기"가 인사이트로 나간다. 균형(수면·운동·경험·자기주도)은 성적과 같은 크기의 카드다.

## 2. 정보 구조

| 탭 | 질문 | 학부모 | 학생 | 멘토 |
|---|---|---|---|---|
| 오늘 | 지금 뭐 하면 되지? | 상태 문장 → 지금 챙길 것 3개(여정 이정표 + 이번 학기 목표 단계) → 오늘의 아이(할 일·일정·타이머 상태) → 격려 카드 | 타이머 큰 버튼 → 오늘 할 것(할 일 + 목표 단계 + 활동 소감) → 오늘 일정 → 부모 한마디 → 추천 영상 1개 | 학생 상태 문장 → 내 과제 진행 → 학급 진도 → 배정 카드 |
| 여정 | 다음은 뭐지? | 구간(학기) 타임라인. 필터 칩: 전체·이정표·목표·활동·건강. 목표 트랙 시작과 로드맵도 이 안의 뷰 | 같은 타임라인, 내 목표 단계 중심 | 로드맵 큐레이팅이 이 탭의 기본 뷰 |
| 기록 (학생은 "나") | 어떻게 하고 있지? | 세그먼트: 균형 · 학습 · 성적 · 재능 | 세그먼트: 진도 · 시간 · 성적 · 활동 | 세그먼트: 진도 · 성적 · 시간 |
| 가족 | 누구와? | 구성원·멘토 모드·자녀 정보(생년월일·학년)·콘텐츠 저장소·알림·설정 | 연결 코드·과목·콘텐츠 저장소·설정 | 담당 학생·담당 과목·설정 |
| + 기록하기 | 무엇을 남길까? | 격려 한마디 · 활동 기록 · 할 일 하나 · 성적 입력 · 일정 추가 | 타이머 · 할 일 · 활동 기록 · 성적 | 과제 배정 · 피드백 메모 · 로드맵 항목 |

코드 대응: `ui/navigation/NextStepNavHost.kt` 가 네 탭과 + 버튼을 그리고, `ui/quickadd/` 가 기록하기 시트, `ui/records/` 가 기록 탭(균형 세그먼트는 `RecordsViewModel`, 나머지 세그먼트는 각 기능 화면을 그대로 품음), `ui/settings/` 가 가족 탭이다. 격려 화면(`CheerScreen`)은 오늘의 격려 카드에서 진입하고, 콘텐츠 저장소는 가족 탭과 오늘의 추천 카드 1개에서 진입한다. 상태 문장은 `domain/stats/BalanceStats` 가 만든다.

## 3. 화면별 규칙

### 오늘
- 첫 카드는 상태 문장. 색은 잘 가고 있으면 초록(브랜드), 챙길 것이 있으면 문장으로만 알리고 색을 바꾸지 않는다(경고색 남발 금지).
- "지금 챙길 것"은 여정에서 계산된 3개. 지난 항목이 있으면 그것이 먼저.
- 학생 화면의 타이머 버튼은 76px 이상. 한 번 누르면 바로 시작(과목 선택은 지난번 과목 기본).

### 여정
- 구간 머리글: 구간 이름 · 기간 · "지금" 배지. 지난 구간은 접힌 한 줄("지난 구간 19개 · 펼치기").
- 항목은 종류 태그(이정표·목표·활동·건강)가 왼쪽에 붙은 한 줄 카드. 탭하면 바텀시트: 왜 지금인지 · 완료 · 메모 · 날짜 · 할 일로 보내기.
- 목표 트랙 시작·직접 목표 만들기·로드맵은 필터 "목표"의 상단 카드에서 진입한다. 별도 탭을 두지 않는다.

### 기록
- 세그먼트 첫 번째는 항상 "균형". 그래프는 화면당 하나, 나머지는 게이지(막대 + 한 줄 설명).
- 모든 지표에 "권장선 안 / 조금 더 / 줄이기" 중 하나의 문장이 붙는다. 백분위·등수·또래 평균은 없다.
- 재능·인사이트 카드는 3개까지, 각각 "할 일로 보내기" 하나.

### 기록하기 시트
- 항목은 역할별 5개 이하. 항목 안 폼은 필수 3필드, 나머지는 "더 적기"로 접는다.
- 저장 후 시트는 닫히고 첫 화면의 해당 카드가 갱신된다(토스트 한 줄).

## 4. 시각 언어

- 바탕: 따뜻한 회백색 `#F4F1EA`, 카드 `#FFFDF8`, 선 `#E3DDD1`. 잉크 `#1B1B1F`, 보조 텍스트 `#5C5A55`.
- 강조 1(성장·행동): 청록 `#1F6F63`. 강조 2(지금·마감): 갈색 주황 `#B8551C`. 둘 다 흰 글자와 4.5:1 이상.
- 서체: 제목 Gowun Batang(명조, 700), 본문 Noto Sans KR. 제목은 26px, 카드 제목 16px, 본문 15px, 보조 13px, 라벨 12px.
- 터치 타깃 44px 이상. 모서리 16px(카드) · 20px(상태 카드) · 완전 둥근 버튼.
- 아이콘은 선 굵기 1.8의 단색 스트로크. 이모지 없음.
