# NextStep UX 가이드

> 기능은 많아지고 화면은 작다. 이 문서는 "생각하지 않고 쓰는" 앱을 지키는 규칙이다. 새 화면·기능은 여기 규칙에 맞지 않으면 구조를 바꾸지 말고 기능을 기존 자리에 넣는다.
> 목업: https://claude.ai/artifact/4PusAYfkqYUC2DR2qRT7Ey (구조) · https://claude.ai/artifact/PNg6oFRuvMFgJEZ17fcNyi (작동 프로토타입, 시각 우선)

## 1. 원칙 (우선순위 순)

1. **화면마다 질문 하나.** 오늘 = "지금 뭐 하면 되지?", 여정 = "다음은 뭐지?", 기록 = "어떻게 하고 있지?", 가족 = "누구와?". 한 화면이 두 질문에 답하면 쪼갠다.
2. **하단 탭은 3개 + 기록 버튼 + 가족.** 역할이 달라도 뼈대는 같다. 하단 탭을 늘리는 대신 새 기능은 (a) 오늘의 카드 한 장, (b) 여정 위의 항목 종류, (c) 기록 탭의 **관심사 › 섹션** 하나로만 들어간다. 기록 탭은 위 줄(관심사)·아래 줄(섹션)의 두 단 탭이라 기능이 늘어도 자리가 모자라지 않는다.
3. **쓰기는 전부 기록 버튼(+)으로.** 화면마다 편집 버튼을 두지 않는다. 시트는 항목 5개 이하, 각 항목은 필수 입력 3개 이하(예: 활동 기록 = 종류·제목·날짜).
4. **숫자보다 상태 문장.** 첫 화면은 "잘 가고 있어요 / 챙길 것 하나"처럼 한 문장으로 답한다. 숫자·그래프는 한 번 탭한 뒤에.
5. **지금 기준 3개.** 모든 목록은 지금 필요한 3개까지만 보여 주고 "전체 보기"로 확장한다. 스크롤로 기능을 발견하게 하지 않는다.
6. **시간이 곧 내비게이션.** 여정은 한 번에 한 해(학년)만 보여 준다. 기본은 올해이고, 학년 띠를 옆으로 넘겨 지난 해(히스토리)와 다음 해(미리 보기)로 간다. 한 해 안에서는 1학기·2학기로 나눈다.
7. **상세는 바텀시트.** 맥락을 유지한다. 전체 화면 전환은 편집기(긴 입력)와 타이머뿐이다.
8. **카드 해부학은 하나.** 라벨(12px 회색) / 제목(16px 굵게, 한 줄) / 보조(13px 회색, 한 줄) / 오른쪽 행동 1개(버튼 또는 화살표). 카드당 행동은 하나.
9. **기록 마찰 0.** 학생 첫 화면 최상단은 타이머 큰 버튼. 완료는 체크 한 번. 활동 기록은 세 필드. 학생 화면엔 광고도 유료 벽도 없다.
10. **비교 없음, 상한 있음.** 또래·전국 비교 지표를 그리지 않는다. 학습량이 성장 단계 상한을 넘으면 "줄이기"가 인사이트로 나간다. 균형(수면·운동·경험·자기주도)은 성적과 같은 크기의 카드다.
11. **채팅·메시지 없음.** 가족·멘토끼리 주고받는 말은 이미 쓰는 메신저의 몫이다. 앱은 기록과 할 일(누가 · 언제까지)로만 이어지고, 격려·메모·피드백 말풍선을 두지 않는다.

## 2. 정보 구조

| 탭 | 질문 | 학부모 | 학생 | 멘토 |
|---|---|---|---|---|
| 오늘 | 지금 뭐 하면 되지? | 자녀 줄(다자녀면) → 상태 카드 → 챙길 것 3개(여정 이정표 + 시험·목표의 다음 단계, 날짜순) → 오늘(시간 띠 + 할 일 n/m). 이것뿐 | 타이머 큰 버튼 → 오늘 할 것(할 일 + 목표 단계 + 활동 소감) → 이번 주 → 오늘 일정 → 추천 영상 1개. 학년 단계만큼만 보인다(아래 "자라는 학생 화면") | 학생 상태 문장 → 내 과제 진행 → 학급 진도 → 배정 카드 |
| 올해 (학생만, 여정 자리) | 올해 뭘 해야 하지? | — (학부모·멘토는 여정) | 분류 탭(전체 · 국어 · 수학 · 영어 · 사회·역사 · 과학 · 독서 · 예체능 · 시험 · 수행·학생부 · 진로·입시 · 생활 · 몸)으로 올해 할 일을 잘게 나눔. 탭 안은 지금 학기 → 1년 내내 → 다른 학기. 여정은 위 버튼으로 | — |
| 여정 | 다음은 뭐지? | 구간(학기) 타임라인. 필터 칩: 전체·이정표·목표·활동·건강. 목표 트랙 시작과 로드맵도 이 안의 뷰 | 같은 타임라인, 내 목표 단계 중심 | 로드맵 큐레이팅이 이 탭의 기본 뷰 |
| 기록 (학생은 "나") | 어떻게 하고 있지? | 관심사 탭: 한눈에 · 공부 · 시험·성적 · 성장 · 활동·재능 (아래 "기록") | 같은 관심사 탭, 화면 단계만큼 | 같은 관심사 탭 |
| 가족 | 누구와? | 자녀(전환·새 자녀·코드로 연결) · 보호자(엄마·아빠·조부모 등 여러 명, 내 관계) · 학생·멘토 · 멘토 겸하기 · 자녀 정보 · 연결 코드 | 연결 코드·과목·콘텐츠 저장소·설정 | 담당 학생·담당 과목·설정 |
| + 기록하기 | 무엇을 남길까? | 시험·목표 · 할 일 하나 · 성적 입력 · 활동 기록 · 일정 | 타이머 · 시험·목표 · 할 일 · 활동 기록 · 성적 | 과제 배정 · 시험·목표 · 로드맵 항목 |

코드 대응: `ui/navigation/NextStepNavHost.kt` 가 네 탭과 + 버튼을 그리고, `ui/quickadd/` 가 기록하기 시트, `ui/hub/` 가 기록 탭(관심사 줄 + 섹션 줄 + 좌우로 넘기는 페이지, 섹션마다 기능 화면 하나), `ui/settings/` 가 가족 탭이다. 콘텐츠 저장소는 가족 탭과 오늘의 추천 카드 1개에서 진입한다. 상태 문장은 `domain/stats/BalanceStats` 가 만든다.

## 3. 화면별 규칙

### 오늘
- 첫 카드는 상태 문장. 색은 잘 가고 있으면 초록(브랜드), 챙길 것이 있으면 문장으로만 알리고 색을 바꾸지 않는다(경고색 남발 금지).
- "지금 챙길 것"은 여정에서 계산된 3개. 지난 항목이 있으면 그것이 먼저.
- 학생 화면의 타이머 버튼은 76px 이상. 한 번 누르면 바로 시작(과목 선택은 지난번 과목 기본).
- "시험·목표" 카드: 날짜가 정해진 목표마다 종류 아이콘 · D-day 알약 · 날짜 비율대로 찍은 단계 점(끝낸 것 청록, 다음 주황, 밀린 것 빨강 테두리, 목표일 깃발) · 다음 단계 한 줄(체크 + 할 일로). 3개까지.

### 자라는 학생 화면 (학년별 단계)
- **학생 화면은 학년과 함께 자란다.** 저학년은 한 번에 받아들일 수 있는 정보가 적다. 그래서 화면은 작게 시작하고, 새 학년(3월)이 되면 카드가 한 칸씩 열린다. 앞 단계의 카드는 없어지지 않는다.

| 단계 | 학년 | 글자 | 오늘 화면 | 탭 · + 시트 | 말투 |
|---|---|---|---|---|---|
| 씨앗 | 학령 전 (만 0~6세) | 1.4배 | 할 일 2개(가장 큰 동그라미 체크) · 이번 주 스티커. 앉아서 공부하는 시기가 아니라 **타이머가 없다** | 오늘·나·가족, + 는 활동 하나 | 아주 짧은 말("오늘 해 볼 것", "다 했어! 최고야") |
| 새싹 | 초1~2 | 1.3배 | + 큰 시작 버튼(타이머) | + 시트에 타이머 | 쉬운 말("다시 보기", "다 했어요!") |
| 떡잎 | 초3~4 | 1.2배 | + 오늘 일정 · 다시 보기(복습) · 추천 영상 | + 시트에 할 일 | 쉬운 말 |
| 줄기 | 초5~6 | 1.1배 | 숫자(분·합계)와 불꽃 연속 일수가 보임 · + 미리 보기(예습) · 시험·목표 · 다가오는 시험 · 이번 학기 배울 것 | 여정 탭, + 시트 전체 | 기본 |
| 가지 | 중1~3 | 1.0배 | + 과목별 진도 · 멘토 로드맵 | 전체 | 기본 |
| 나무 | 고1 이상 | 1.0배 | + 여정 카드 · 학습 계획 만들기 | 전체 | 기본 |

- **단계가 오른 날**: 오늘 화면 맨 위에 "한 뼘 자랐어요 · 떡잎 화면이 열렸어요" 카드가 붙고, 새로 생긴 카드 이름을 보여 준다. "좋아요"를 누르면 닫힌다. 처음 설치한 날에는 띄우지 않는다.
- **학부모가 고를 수 있다.** 가족 탭 "아이 화면"에서 기본은 "학년에 맞춰 자동"이고, 아이 속도에 맞춰 한 단계 낮추거나 높일 수 있다. 고른 값은 동기화되어 아이 기기에 바로 반영된다. 낮춘 단계에서는 "새 화면" 카드가 뜨지 않는다.
- 단계를 몰라도 되는 경우(학년·생년월일이 없음)는 전체 화면(나무)을 쓴다.

### 해마다 다른 학생 화면 (만 0세 ~ 고3)
단계(씨앗~나무)는 큰 틀이고, 그 안에서 **해마다** 배우는 것과 양이 다르므로 학생 화면은 매년 달라진다. 한 해 = 하나의 `YearProfile`.

| 해 | 올해 한 줄 | 하루 권장 | 먼저 보이는 카드 | 올해의 공부(예) |
|---|---|---|---|---|
| 만 0~2세 | 대화·몸 놀이 / 첫 단어 / 말이 트임 | 0분(놀이만) | 할 일 | 말 걸기, 그림책, 몸 놀이 |
| 만 3~6세 | 놀이로 배움 → 학교 갈 준비 | 10 → 20분 | 할 일 | 함께 읽기, 영어 노래, 한글 놀이, 20분 앉아 있기 |
| 초1 | 한글과 학교생활 | 20분 (10×2) | 할 일 · 올해의 공부 | 소리 내어 읽기, 받아쓰기, 수학 익힘, 알림장 |
| 초2 | 구구단과 혼자 읽기 | 30분 | 올해의 공부 | 구구단, 그림일기, 혼자 읽기 |
| 초3 | 사회·과학·영어 시작 | 40분 | 올해의 공부 | 영어 듣기, 분수 처음, 관찰 기록, 독서록 |
| 초4 | 단원평가로 확인 | 50분 | 복습 | 단원평가 복습, 큰 수·각도 |
| 초5 | 수학 고비, 한국사 시작 | 60분 | 복습 · 올해의 공부 | 약수·배수·분수, 한국사 읽기, 수행평가 |
| 초6 | 중학교 준비 | 70분 | 예습 | 비와 비율, 영어 문법 기초, 진로 찾기 |
| 중1 | 자유학기: 수행평가·진로 | 80분 | 올해의 공부 | 정수·유리수, 수행평가, 진로 탐색 |
| 중2 | 첫 지필평가 | 100분 | 시험·목표 | 중간·기말 대비, 일차함수, 역사 |
| 중3 | 고등학교 고르기 | 120분 | 시험·목표 | 기말·수행, 이차방정식, 고교 선택 |
| 고1 | 고교학점제·내신·학생부 시작 | 150분 | 시험·목표 · 올해의 공부 | 내신, 공통수학, 모의고사, 세특 기록 |
| 고2 | 선택과목·진로 | 180분 | 시험·목표 · 과목별 진도 | 선택과목 내신, 탐구 보고서 |
| 고3 | 수능·수시 | 210분 | 시험·목표 · 학습 계획 | 수능 기출, 모평 복기, 원서, 수면 지키기 |

- **해마다 바뀌는 것:** 오늘 화면 제목 아래 올해 한 줄, 타이머의 "오늘 목표 N분", "올해의 공부" 카드(종류 · 주 몇 회 · 몇 분, + 로 오늘 할 일), 올해 과목, 카드 순서, 글씨 크기(1.4배 → 초1 1.3 → … → 중1 1.0), 할 일 줄 수, 학습 계획 기본값(한 번 길이·횟수·주말), 균형 판단의 권장선(하루 권장 × 주당 일수).
- 하루 권장량은 **상한에 가깝게** 잡는다. 넘으면 "줄이기"가 나간다.
- 학부모가 단계를 직접 고르면 그 단계의 글씨·줄 수를 쓰고, 공부 종류와 양은 여전히 올해 것을 쓴다.
- 코드 대응: `domain/growth/YearProfiles`(21개 해: 만 0~6세, 초1~고3, 대학, 대학원), `YearProfile`, `StudyKind`, `StudentScreen.of(student)`(단계·올해·글씨·줄 수·카드 순서를 한 번에). 화면은 `StudentScreen` 값만 읽는다.

### 아이가 직접 쓰는 앱 (아이 모드)
학령 전에는 부모가 대신 체크하더라도 언젠가 아이가 자기 폰으로 쓴다. 그래서 학생 모드는 **아이 혼자서도 쓸 수 있게** 학년에 맞춰 도움 장치를 켜고, 학년이 오르면 하나씩 끈다.

| 도움 장치 | 학령 전·초1~2 | 초3~4 | 초5~ |
|---|---|---|---|
| 나 탭 = 스티커판(공부한 날 별 · 활동한 날 꽃 · 이번 주 체크 · 한 것) | ✓ | 기록 허브 | 기록 허브 |
| 가족 탭 = 가족 얼굴, 설정은 어른 확인 뒤 | ✓ | ✓ | 일반 설정 |
| + = 그림 타일 한 번("책 읽었어요" · "운동했어요" · "악기 연습했어요" …), 양식 없음 | ✓ | ✓ | 일반 시트 |
| 할 일 스피커: 눌러서 소리로 듣기 | ✓ | | |
| 타이머 = 줄어드는 원(올해 한 번 공부 길이), 버튼은 "시작!" / "다 했어요" | ✓(새싹부터) | ✓ | 숫자 타이머 |

- **어른 확인:** 아이 모드의 설정·연결 해제는 두 자리 × 한 자리 곱셈 하나를 맞혀야 열린다. 보안이 아니라 실수로 들어가지 않게 하는 문턱이다. 틀리면 새 문제.
- **글보다 그림, 한 번에 끝:** 아이 화면의 모든 쓰기는 한 번 누르기다. 입력칸이 나오는 곳은 어른 확인뿐이다.
- 코드 대응: 켜고 끄는 값은 `domain/growth/KidMode`(단계마다 `StudentUiLevel.kid`), 그림 타일 `KidRecord`, 어른 확인 `domain/access/ParentGate`, 스티커판 `domain/stats/StickerStats`. 화면은 `ui/kidme/`, `ui/kidfamily/`, `ui/quickadd/components/KidRecordGrid`, `ui/timer/components/KidTimerCard`, 읽어 주기 `ui/components/speech/rememberSpeaker`.

### 가장 어린 나이의 과열 가드 (만 0~6세)
서울은 만 2~3세부터 사교육이 시작되고 만 5세면 10명 중 8명이 받는다(2024 유아 사교육비 조사). '4세 고시'(영어유치원 입학시험), '7세 고시'(초등 어학원 입학시험)가 생길 만큼 과열돼 있다. 앱은 더 하라고 밀지 않고, 가장 어린 나이부터 **줄여도 된다**를 먼저 말한다.
- **앉아서 하는 공부:** 영아·유아(권장선 0)는 학습 기록이 있으면 "줄이기". 유치원기는 하루 15분 권장선.
- **학원·수업 상한:** 영아 주 1시간 · 유아 주 2시간 · 유치원기 주 5시간(문화센터·놀이 수업·영어 수업 포함, 일정의 학원·수업 종류로 계산). 넘으면 상태 문장이 "학원·수업이 많아요. 놀 시간이 남아 있는지 봐 주세요"로 바뀌고 균형 카드에 게이지가 붙는다. 또래가 얼마나 하는지는 보여 주지 않는다.
- **여정 이정표:** 전집·교구 권유 거르기(9개월) → 문화센터·놀이 수업은 주 1~2개(26개월) → 영어유치원 고르기 전 확인(레벨테스트 금지 2026.10~, 40개월) → '7세 고시' 대신 매일 함께 읽기(62개월).
- 코드 대응: `BalanceStats.classCapWeekMinutes`·`classWeekMinutes`, `BalanceReport.classVerdict`, `MilestoneCatalog` 의 early-kit-pass · class-limit-toddler · english-kinder-check · reading-over-cramming.
- 코드 대응: 단계와 카드 목록은 `domain/growth/StudentUiLevel` 한 곳에서 정한다. 화면은 `level.shows(StudentHomeSection.X)`, `level.words`, `level.textScale` 만 읽고 학년으로 분기하지 않는다. 글자 배율은 `NextStepRoot` 의 `StudentTextScale`, 탭·+ 시트는 `RootUiState.studentLevel` 을 따른다.

### 학부모 화면 (더 단순하게)
- 학부모 첫 화면은 네 덩어리뿐이다: 자녀 줄 · 상태 카드 · 챙길 것 3개 · 오늘. 재능·분석·성장 단계 팁은 기록 탭으로 보낸다.
- 글자는 한 단계 크게(카드 제목 16px, 섹션 19px, 상태 문장 25px). 카드마다 행동은 하나.
- "챙길 것"은 여정 이정표와 시험·목표의 다음 단계를 하나의 목록으로 합쳐 날짜순 3개만. 목표 이름은 단계 아래 작은 글씨 한 줄.
- 오늘의 할 일은 목록 대신 "할 일 2/4" 알약 하나. 목록은 눌러서 기록 탭에서 본다.

### 다자녀·여러 보호자
- **자녀마다 공간이 따로다.** 기록·여정·목표·성장은 자녀별로 쌓인다(앱에서는 자녀마다 familyId). 학부모 기기는 연결된 자녀 목록을 기억하고 오간다.
- **자녀 줄.** 학부모 오늘 화면 맨 위, 자녀마다 이니셜 원 + 이름 + 학년, 챙길 것이 있으면 주황 숫자, 없으면 체크. 누르면 그 자녀로 바뀌고 모든 탭이 따라간다. 끝에 점선 "+ 자녀".
- **자녀 추가는 두 길.** 자녀가 아직 앱을 안 쓰면 "새 자녀"(이름·생년월일 두 칸), 자녀나 다른 보호자가 이미 만들었으면 "코드로 연결". 이름·관계·멘토 겸하기는 새 자녀에도 그대로 이어진다.
- **보호자는 여러 명.** 엄마·아빠·할머니·할아버지·보호자 관계를 고르고, 가족 탭 보호자 칸에 관계 이니셜 원으로 모두 보인다. 배정 표시는 이름 대신 관계로("할머니 배정").
- **학생은 자기 공간 하나.** 학생 화면에는 자녀 줄이 없다. 여러 학생을 맡은 멘토는 멘토 홈 위에 같은 줄로 학생을 오간다.
- 코드 대응: `data/prefs/LinkedChild`, `OnboardingRepository.addChildAsParent/linkChild/switchChild`, `ui/components/input/ChildSwitcher`, `data/model/GuardianRelation`, `MemberEntity.roleLabel`.

### 여정
- **한 화면 = 한 해.** 여러 학년의 항목을 한 목록에 섞지 않는다. 영아·유아·유치원은 단계별로 한 칸, 초1부터 고3까지는 학년마다 한 칸(3월–이듬해 2월), 대학은 한 칸이다.
- **학년 띠.** 화면 맨 위에 가로로 넘기는 학년 칩을 둔다. 칩 표시: 지난 해는 완료율 링(다 끝나면 체크), 올해는 주황 링, 다음 해는 점선 원. 영유아·초등·중등·고등·대학 사이에는 세로 구분 글자를 둔다. 여정 탭을 다시 누르면 올해로 돌아온다.
- **해 머리 카드.** 학년 이름과 상태 배지(지금 · 지난 해 · 미리 보기), 기간과 만 나이, 좌우 화살표로 이전·다음 해. 그 아래 3월–2월 한 해 막대에 1학기·2학기 구간과 항목 점(종류 색), 올해면 오늘 선. 종류별 완료/전체 알약과 한 해 완료율 링.
- **본문.** 1학기 → 2학기 순서. 남은 항목이 위, 완료·건너뜀은 "✓ n" 한 줄로 접힌다(올해). 지난 해는 전부 펼쳐 흐리게 보여 준다.
- **히스토리.** 지난 해를 열면 머리 카드 아래 "한 해 돌아보기" 카드가 붙는다: 완료 수, 그해 키와 전년 대비 변화, 활동 수, 가족이 남긴 한 줄 기억. 지난 해 항목도 바텀시트에서 다시 열 수 있다.
- **모아보기.** 앱 바의 격자 버튼이 모든 해를 단계별 격자(해마다 링 + 종류 색 점)로 보여 준다. 칸을 누르면 그 해로 간다. 목록 버튼으로 한 해 보기로 돌아온다.
- 항목은 종류 아이콘이 왼쪽에 붙은 한 줄 카드. 탭하면 바텀시트: 왜 지금인지 · 완료 · 할 일로 보내기 · 건너뛰기 · 날짜.
- 목표 트랙 시작·직접 목표 만들기·로드맵은 필터 "목표"의 상단 카드에서 진입한다. 별도 탭을 두지 않는다.
- 코드 대응(앱 반영 시): 학년 목록은 `domain/journey/PeriodCalendar` 의 구간을 해 단위로 묶어 만들고, 선택한 해는 `JourneyViewModel` 의 상태(`selectedYear`)로 둔다. 해 요약은 `JourneySections` 에서 해마다 한 번 계산한다.

### 올해 (학생 탭)

- 학생의 하단 탭은 **오늘 · 올해 · + · 나 · 가족**. 여러 해를 보는 여정 대신 "올해 할 일"을 가장 가까운 자리에 둔다(학부모·멘토는 여정 그대로).
- 올해 할 일은 `domain/year/YearPlans` 한 곳에 해마다(a0~a6, e1~e6, m1~m3, h1~h3, u, g) 적는다. 분류는 `YearArea`, 때는 `YearTerm`(1학기·2학기·1년 내내). 화면은 그 해에 할 일이 있는 분류만 탭으로 만든다: 만 0~2세는 말·놀이·생활·몸 네 개, 고3은 시험·진로·입시까지.
- **누가 하는지 붙인다**(`YearDoer`: 엄마·아빠가 · 같이 · 스스로). 만 0~1세는 전부 부모가·같이 하는 일이고("0세가 그림책을 읽는다" 같은 줄은 없다), 만 3세부터 "스스로"가 생긴다. 학령 전은 모든 줄에, 학교부터는 "스스로"가 아닌 줄에만 칩을 단다.
- 전체 탭 맨 위에 그 나이의 **주변에서는 / 우리는** 카드(`YearTrends`): 조사 숫자로 본 교육열과 이 앱의 권장 기준.
- **한 목록, 세 사람의 몫.** 그 해 할 일은 학업·생활(`YearPlans`) + 건강 체크리스트(`HealthPlans`: 접종·영유아 검진·학생 건강검사·정서행동검사·치과·시력·마음) + 부모의 지원·서류·상담(`ParentPlans`) + 멘토 코칭(`MentorPlans`)을 합친 것이다. 누가 하는지는 엄마·아빠가 · 같이 · 스스로 · 멘토가.
- 기본은 **내 할 일**(`Capabilities.yearDoers`: 학생 = 스스로·같이, 학부모 = 엄마·아빠가·같이, 멘토 = 멘토가)이고 "가족 전체"로 바꿀 수 있다. 내 몫이 없으면 전체를 보여 준다. 학부모·멘토는 여정 위 "올해" 버튼으로 연다.
- 할 일 한 줄 = 제목 + 방법·분량 한 줄. 누르면 상세 시트(오늘 할 일로 · 다 했어요). 완료 표시는 여정 저장소에 `year:` 키로 남아 가족 기기와 동기화된다.
- 양은 상한에 가깝게 적는다: 더 시키려는 목록이 아니라 "이만큼이면 충분한" 목록이다.

### 학년은 보이는 곳에 두지 않는다

- 학년·생년월일·아이 화면 단계는 한 번 정하면 1년을 간다. 그래서 고르는 칩을 화면에 늘어놓지 않는다. 가족 탭에는 "초5 · 2015. 7. 3생 · 3월에 자동으로 올라가요" 요약 한 줄과 **고치기** 버튼만 둔다.
- 고치기 창 안에서만 생년월일·학년·화면 단계를 바꾸고, "바꾸기"를 눌러야 저장된다(바뀐 값만 씀). 학년은 생년월일로 3월마다 자동으로 오른다.
- 학년을 고르는 칩이 보이는 곳은 첫 설정(온보딩)과 이 고치기 창뿐이다.

### 기록 (관심사 허브)
기능이 많아도 한 화면에 섞지 않는다. **기능 하나 = 섹션 하나, 섹션은 반드시 한 관심사에만 속한다.**

| 관심사 | 질문 | 섹션(= 기능 화면) |
|---|---|---|
| 한눈에 | 전체적으로 어때? | 균형 카드 + 관심사 타일 2열(타일마다 큰 한 줄 · 작은 한 줄 · 먼저 볼 곳이면 주황 점, 누르면 그 관심사로) |
| 공부 | 얼마나, 어떻게 공부하고 있지? | 진도 · 시간 · 습관(언제·한 번에 얼마나·며칠 이어서, 지난주와 비교) · 일정 |
| 배울 것 | 지금 무엇을 공부하면 되지? | 이번 학기 · 복습(이해도 낮음 → 점수 내려간 과목 → 수업 뒤 → 다음 수업 예습, 줄마다 "할 일로") · 영상 · 로드맵 |
| 시험·성적 | 시험 준비와 결과는? | 시험·목표 · 성적 |
| 과제 | 받은 과제는 어떻게 되고 있지? | 과제(멘토가 낸 과제: 밀린 것 → 이번 주 마감 → 과목별 완료 → 최근 끝낸 것) |
| 성장 | 몸은 잘 자라고 있지? | 신체(요약 → 키 추이 → 연도별 전체 기록). 멘토에게는 보이지 않는다 |
| 활동·재능 | 무엇을 좋아하고 잘하지? | 활동 · 재능(신호 → 영역별 관찰 메모 전체) |

- **역할마다 순서가 다르다.** 같은 관심사라도 먼저 보고 싶은 것이 다르다(`domain/hub/HubAudience`).
  - 학부모: 한눈에 · 공부 · 배울 것 · 시험·성적 · 과제 · 성장 · 활동·재능
  - 학생("나"): 한눈에 · **배울 것** · 공부 · 시험·성적 · 과제 · 활동·재능 · 성장
  - 멘토: 한눈에 · **과제** · 공부 · 배울 것 · 시험·성적 · 활동·재능 (신체 기록 없음)
- **두 단 탭.** 위 줄은 아이콘 + 이름의 관심사 탭(가로 스크롤), 아래 줄은 그 관심사의 섹션 알약(가로 스크롤). 섹션이 하나뿐인 관심사는 아래 줄을 숨긴다.
- **옆으로 밀기.** 관심사는 페이지라 화면을 좌우로 밀어 넘긴다. 관심사마다 마지막으로 본 섹션을 기억한다.
- **많은 데이터는 여기서.** 오늘 화면의 "3개까지" 규칙은 기록 탭에는 적용하지 않는다. 섹션은 전체 목록을 보여 주되, 연도·영역처럼 묶을 기준이 있으면 머리를 위에 붙여(sticky) 스크롤해도 어디인지 보이게 한다. 맨 위에는 항상 요약 카드 한 장.
- **제목줄 없음.** 섹션 화면은 기록 탭 안에서 자기 제목줄을 그리지 않는다(관심사·섹션 줄이 제목이다). 다른 탭의 카드에서 같은 기능을 열면 뒤로 가기가 있는 전체 화면으로 열린다.
- **오늘 → 기록 바로가기.** 오늘 카드의 "전체"는 해당 섹션을 바로 연다(예: 할 일 전체 → 공부 › 일정).
- 코드 대응: 관심사·섹션과 보이는 조건은 `domain/hub/Concern`·`ConcernSection`, 한눈에 타일 문구는 `domain/hub/ConcernDigests`. 화면은 `ui/hub/HubScreen`(두 단 탭 + 페이저), `ui/overview/`(한눈에), `ui/growth/`(신체), `ui/talent/`(재능), `ui/habits/`(습관), `ui/review/`(복습), `ui/assignments/`(과제), 나머지 섹션은 기존 기능 화면. 보는 사람은 `HubViewer.of(caps, level)` 하나로 정한다.
- **학생은 단계만큼.** 씨앗은 한눈에 · 성장 · 활동만(공부 관심사 없음), 새싹은 여기에 공부(시간), 싹(초3)부터 습관 · 복습 · 영상, 줄기부터 이번 학기 · 시험·성적 · 과제, 가지부터 로드맵까지 보인다.
- 그래프는 섹션당 하나, 나머지는 게이지(막대 + 한 줄 설명).
- 모든 지표에 "권장선 안 / 조금 더 / 줄이기" 중 하나의 문장이 붙는다. 백분위·등수·또래 평균은 없다.
- 재능·인사이트 카드는 3개까지, 각각 "할 일로 보내기" 하나.

### 기록하기 시트
- 항목은 역할별 5개 이하. 항목 안 폼은 필수 3필드, 나머지는 "더 적기"로 접는다.
- 저장 후 시트는 닫히고 첫 화면의 해당 카드가 갱신된다(토스트 한 줄).

## 4. 시각 언어

## 4-1. 글보다 그림 (시각 우선 규칙)

화면에 문장을 늘리기 전에 아래 표현을 먼저 쓴다. 문장은 바텀시트의 "왜 지금인지" 한 줄, 칭찬 말풍선, 빈 상태 안내에만 둔다.

| 전하려는 것 | 쓰는 표현 | 쓰지 않는 표현 |
|---|---|---|
| 이번 주 상태 | 상태 카드의 링(주간 학습 / 권장 상한) + 한 줄("잘 가고 있어요") + 학습·주도·경험 아이콘 배지와 색 점 | 설명 문단, 숫자 타일 3개 |
| 균형 판정 | 영역별 작은 링 5개(학습·주도·경험·수면·운동), 색이 판정(청록 권장선 안 · 주황 조금 더 · 빨강 줄이기) | 막대 + 설명 문장 |
| 항목 종류 | 색 사각 아이콘(깃발 이정표 · 과녁 목표 · 별 활동 · 하트 건강) | "이정표" 같은 글자 태그 |
| 마감 | D-day 알약. 7일 이내 연주황, 지남은 주황 채움, 완료는 체크 | "4월 10일까지" 같은 문장 |
| 오늘 일정 | 14~22시 가로 시간 띠에 블록 + 현재 시각 선 + 공부한 구간 | 일정 카드 목록 |
| 연속 학습 | 불꽃 + 요일 점 7개 | "3일 연속으로 공부했어요" |
| 진도·커리큘럼 | 단원 점(채움 복습 · 반 채움 수업 · 주황 테두리 다음 · 점선 미등록) | "학급 4/8 · 복습 3/8" 문장 |
| 성적 | 과목 배지 + 추세선 + 최근 점수 + 화살표 | 점수 목록 |
| 재능 | 9개 영역 레이더, 상위 2개 강조 | 강점 설명 카드 |
| 목표·로드맵 | 학기별 단계 점을 잇는 스테퍼 | 단계 목록 |
| 사람 | 역할 색 이니셜 원(학부모 주황 · 학생 청록 · 멘토 보라) | "엄마 (학부모) · 4월 13일" |
| 과목 | 과목 색 사각 배지에 첫 글자 | 과목명 글자 |
| 행동 | 아이콘 버튼(체크 완료 · 목록 할 일로 · 건너뛰기 · + 추가 · × 취소), 접근성 라벨은 필수 | "할 일로 보내기" 텍스트 버튼 |
| 기록하기 시트 | 아이콘 타일 격자, 라벨 한 단어 | 제목 + 설명 두 줄 목록 |

- 카드 한 장에 문장은 최대 한 줄. 두 줄이 필요하면 바텀시트로 보낸다.
- 섹션 제목은 두 글자에서 네 글자("챙길 것", "할 것", "성장"). 설명 부제는 두지 않는다.
- 숫자는 링·점·막대 옆에 하나만. 같은 값을 숫자와 문장으로 두 번 쓰지 않는다.
- 색만으로 뜻을 전하지 않는다. 판정 링 아래에는 "권장선 안/조금 더/줄이기" 한 단어를 붙이고, 아이콘 버튼에는 라벨을 단다.
